# 🎬 MoviePlanet

**MoviePlanet** é uma app para descobrir e gerir os teus filmes! Vais poder explorar catálogos, comentar, avaliar e organizar os seus filmes favoritos.

## 🚀 Funcionalidades

- Autenticação com registo/login e JWT
- Catálogo de filmes com filtros e pesquisa
- Página de detalhes com sinopse, elenco, avaliações
- Listas personalizadas: Favoritos, Vistos, Para Ver
- Comentários e avaliações de filmes
- Interface responsiva com tema espacial

## 🛠️ Tecnologias

### Frontend
- React.js + TypeScript
- Axios
- Bootstrap

### Backend
- Node.js + Express
- MongoDB + Mongoose
- JWT
- Bcrypt
- CORS Middleware

### Infraestrutura
